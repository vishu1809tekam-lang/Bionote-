# 🧬 BioNotes

BioNotes is a free biotechnology study website built to help students learn through structured notes, MCQs, practicals, and previous-year papers.

🌐 Live Website:
https://vishu1809tekam-lang.github.io/Bionote-/

---

## ✨ Features

- 📖 Topic-wise biotechnology notes
- ✅ Practice MCQs
- 🧪 Practical write-ups
- 📄 Previous year papers
- 🔍 Search functionality
- 📱 Mobile-friendly responsive design
